# 作业提交助手

作业提交助手是一款面向课程作业整理流程的微信小程序。项目希望把拍摄作业、整理图片、生成 PDF 和按课程规则命名等步骤集中起来，减少学生在相册、扫描应用和文件管理工具之间反复切换的麻烦。作业仍由学生通过老师指定的渠道提交，本项目不代替学生提交。

## 项目背景

本项目从微信小程序官方示例模板开始开发，由一名计算机相关专业的大一学生作为个人学习项目维护。开发者正在通过实际项目学习小程序开发。第一阶段计划供班级内不超过 10 人小范围试用；具体完成日期待定。

## 规划中的使用流程

课程列表 → 课程章节选择 → 拍照或选择图片 → 检查、排序、旋转、删除或重拍 → 生成并预览按规则命名的 PDF → 手动导出。

页面跳转和完整处理流程仍在开发中。实际课程与章节、以及每门课程对应的文件命名规则由项目维护者统一配置；学生不自行设置规则。命名示例（实际规则待维护者确认）：

```text
学号 姓名 LectureX.pdf
```

## 技术与项目结构

当前项目是原生微信小程序结构，使用 JavaScript、WXML、WXSS 和 JSON 配置文件；没有发现已配置的第三方前端框架或依赖安装清单。

```text
app.js / app.json / app.wxss   小程序入口、页面注册与全局样式
pages/home/                    首页与课程入口
pages/submit/                  作业处理页面
pages/profile/                 个人信息页面
utils/subjects.js              课程、章节标签及本机编号存储
utils/api.js                   预留的后端上传、PDF 生成和下载请求
utils/config.js                后端服务地址
```
